## Usage

`Actionnable` est une surface d'interaction polymorphique qui ajoute des effets de ripple (hover, focus, touch) à n'importe quel élément.

## Ripple target

Par défaut, `Actionnable` s'observe lui-même. Passer `rippleTarget` ou `focusTarget` permet de déléguer l'écoute des événements à un élément extérieur (ex : le bouton natif wrapé par `Actionnable`).

## Désactiver les ripples

```tsx
<Actionnable disableRipples>...</Actionnable>
<Actionnable disableHoverRipple>...</Actionnable>
<Actionnable disableFocusRipple>...</Actionnable>
<Actionnable disableTouchRipple>...</Actionnable>
```
